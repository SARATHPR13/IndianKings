# Indian Kings — Unciv Mod

*Nineteen historical Indian dynasties, brought to life in Unciv — from Ashoka's Maurya Empire to Ranjit Singh's Sikh Empire. Each civilization has a unique ability, unit, building, land improvement, full-color leader portrait, and a Civilopedia entry that actually explains what everything does.*

**If you enjoy this mod, leaving a ⭐ star is appreciated — it helps other players find it!**

Every civilization also has:
- **2 unique Nation abilities** — gold, science, culture, growth, or military bonuses
- **Full leader dialogue** — introductions, declaring war, defeat, greetings, trade requests
- **A historically-themed city name list**
- **A Civilopedia entry** that explains the leader's background and exactly what their ability, unit, building, and improvement do
- **Full-color artwork** — a leader portrait plus illustrated unit, building, and improvement art, on top of the flat icons the base game UI needs

## Install on Desktop
1. Find your Unciv install folder (where the `.jar` lives) and create a `mods` folder there if needed.
2. Download this repo as a zip (or `git clone` it) into `mods/IndianKings/`.
3. Restart Unciv. Enable **IndianKings** under Mod rulesets when starting a new game.

## Install on Android / mobile
1. Open Unciv → **Mods** → **Download mod from URL**.
2. Paste this repo's URL (or a release zip link).
3. Once downloaded, start a new game and tick **IndianKings** in the extension mods list alongside your base ruleset.

## Notes
- Artwork (leader portraits, unit/building/improvement illustrations) was generated with Google Gemini and adapted for Unciv's portrait system; the flat white icons used by the core UI were hand-drawn.
- This mod adds civilizations on top of the standard ruleset — it won't conflict with other expansion mods.
- Found a bug or have a civ suggestion? Open an issue on this repo.
